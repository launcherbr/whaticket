# Requisitos de Uso

🚨 ATENÇÃO! Informações cruciais antes de iniciar a instalação: 🚨

1️⃣ Sistema Operacional: Utilize Ubuntu 22.04. 🐧

2️⃣ Recursos Mínimos:

* 4 vCPUs 💪
* 6 GB de RAM 🧠

3️⃣ Recursos Recomendados:

* 4 vCPUs 💪
* 8 GB de RAM 🧠

{% hint style="info" %}
Recomendamos VPS AMD64 (ou x86\_64)  para i386 e ARM64 consulte a seção de Correções e Dicas.
{% endhint %}
